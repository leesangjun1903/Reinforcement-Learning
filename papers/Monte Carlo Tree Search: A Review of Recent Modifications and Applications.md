## 2. 연구의 목적과 필요성

### 2.1 해결하려는 문제: “기본 MCTS를 그대로 적용하면 충분한가?”

**[저자 종합]** 저자들이 정의하는 실질적인 어려움은 단순히 문제의 상태 수가 크다는 사실이 아니라, **현실적인 계산 제약 아래에서 기본 MCTS가 기대한 결과를 내지 못한다는 것**입니다. 더 많은 계산이 도움이 되는 경우도 있지만, 응답 시간·하드웨어 비용·메모리·병렬화 한계 때문에 계산량을 무한히 늘릴 수는 없습니다. **[p.2]** 2103.04931v4

이 문제는 특히 다음과 같이 나타납니다.

| 문제 | 기본 MCTS에 생기는 어려움 | 리뷰가 검토하는 대응 |
|---|---|---|
| 행동 선택지가 지나치게 많음 | 트리가 넓어지기만 하고 중요한 미래를 깊게 조사하지 못함 | 행동 축소, 여러 행동을 묶는 방법, 점진적 확장 |
| 긴 시뮬레이션과 드문 보상 | 한 번의 평가가 비싸거나, 유용한 결과를 얻기까지 오래 걸림 | 조기 종료, 평가함수, 학습된 가치 예측 |
| 상대방의 상태를 볼 수 없음 | 하나의 실제 상태를 전제로 만든 탐색이 잘못된 정보를 이용할 수 있음 | 가능한 상태의 표본화, 정보집합 기반 탐색 |
| 제한된 실시간 예산 | 충분한 시뮬레이션을 수행하지 못함 | 병렬화, 문제 단순화, 오프라인 탐색과 온라인 실행 분리 |

이 구분은 원문의 문제 설정과 각 절의 구성에 근거합니다. **[pp.17–18, 23–28, 66–67, 75–76]** 2103.04931v4 2103.04931v4 2103.04931v4 2103.04931v4 2103.04931v4

> **용어 설명 — 희소 보상:** 행동 대부분에서는 유용한 점수를 받지 못하고, 드문 성공이나 마지막 결과에서만 보상을 받는 상황입니다.

## 4. 방법과 구조: 무엇을 어떻게 수정하는가?

### 4.1 기본 MCTS: 학습된 단일 모델이 아니라 반복적인 탐색 절차

**[원문 설명]** 논문은 기본 문제를 마르코프 의사결정 과정으로 설명하며, 상태 집합, 가능한 행동, 상태 전이, 보상으로 구성합니다. 탐색 트리에서는 노드가 상태를, 간선이 행동을 나타냅니다. **[pp.2, 10]** 2103.04931v4 2103.04931v4

> **용어 설명 — 마르코프 의사결정 과정, MDP:** 현재 상태와 선택한 행동을 알면 다음 상태와 보상을 확률적으로 기술할 수 있는 순차적 의사결정 모형입니다.

한 번의 MCTS 반복은 **선택 → 확장 → 시뮬레이션 → 결과 역전파**로 진행됩니다. 현재까지 만든 트리를 따라 내려가고, 새 노드를 추가한 다음, 미래를 시뮬레이션하여 얻은 결과로 방문 경로의 통계를 갱신합니다. **[pp.11–12, Fig.1]** 2103.04931v4

> **용어 설명 — 롤아웃:** 현재 상태에서 앞으로 행동을 이어 가며 결과를 추정하는 시뮬레이션입니다.  
> **용어 설명 — MCTS의 역전파:** 시뮬레이션 결과를 조상 노드의 통계에 반영하는 절차입니다. 신경망의 가중치를 미분으로 갱신하는 역전파와는 다릅니다.

#### 탐색 도중의 행동 선택: UCT

원문 **식 (2), p.12**는 다음과 같습니다.

```math
a^*
=
\text{arg\,max}_{a\in A(s)}
\left[
Q(s,a)
+
C\sqrt{\frac{\ln N(s)}{N(s,a)}}
\right].
```

여기서 $s$는 현재 상태, $a$는 후보 행동, $A(s)$는 가능한 행동 집합입니다. $Q(s,a)$는 해당 행동의 지금까지의 평균 시뮬레이션 결과, $N(s)$는 상태 방문 횟수, $N(s,a)$는 그 상태에서 행동을 선택한 횟수이며, $C$는 탐색 강도를 조절하는 상수입니다. 원문에서는 각 행동을 먼저 한 번씩 조사한 뒤 이 식을 적용합니다. 2103.04931v4

> **용어 설명 — 활용과 탐색:** 활용은 지금까지 좋아 보인 행동을 더 조사하는 것이고, 탐색은 아직 충분히 조사하지 않은 행동에 기회를 주는 것입니다.  
> **용어 설명 — UCT:** 평균 결과와 탐색 보너스를 함께 사용하여 트리에서 다음 행동을 고르는 기준입니다.

**[해석]** 첫 항은 현재 성과를, 두 번째 항은 정보 부족을 반영합니다. 따라서 평균 점수가 조금 낮아도 조사 횟수가 적은 행동은 다시 선택될 수 있습니다.

반면, 실제 환경에서 실행할 최종 행동을 고르는 원문 **식 (1), p.11**은 다음과 같습니다.

$$
a^*=\text{arg\,max}_{a\in A(s)}Q(s,a).
$$

이 식의 기호는 위와 같습니다. **탐색 도중의 선택 기준과 탐색 종료 후의 실행 행동 선택 기준은 구분해야 합니다.** 이 리뷰의 기본 설명은 최종 선택에 평균값을 사용합니다. 2103.04931v4

**한계.** 유망해 보이는 행동이 드물지만 결정적인 반격에 취약한 경우, 평균적인 시뮬레이션 결과만으로는 그 반격을 늦게 발견할 수 있습니다. 리뷰는 이러한 전술적 함정에 대응하기 위해 얕은 미니맥스 탐색을 결합하는 연구도 소개합니다. **[p.23]** 2103.04931v4

> **용어 설명 — 미니맥스:** 상대가 나에게 가장 불리한 행동을 한다고 가정하고, 그 상황에서도 가장 좋은 선택을 찾는 탐색 방식입니다.

### 4.2 행동 축소와 옵션: 탐색 단위를 바꾼다

**[원문 설명]** 옵션 기반 MCTS는 개별 행동 대신 특정 하위 목표를 달성하는 행동 묶음을 선택합니다. 예를 들어 “오른쪽으로 한 칸 이동” 대신 “목표 구역까지 이동”을 탐색 단위로 사용합니다. 이는 동일한 시간에 더 먼 미래를 조사하도록 돕습니다. **[pp.18–19, Fig.3]** 2103.04931v4

원문은 옵션을 $(I,\mu,\beta)$로 표현합니다. $I$는 옵션을 시작할 수 있는 상태 집합, $\mu$는 옵션 내부에서 행동을 선택하는 정책, $\beta$는 옵션의 종료 조건입니다. **[p.42]** 2103.04931v4

> **용어 설명 — 정책:** 주어진 상태에서 어떤 행동을 선택할지 정하는 규칙 또는 확률분포입니다.  
> **용어 설명 — 시간적 추상화:** 여러 시간 단계의 행동을 하나의 의미 있는 단위로 묶는 것입니다.

빔 MCTS는 특정 깊이에서 일부 유망한 노드만 유지하고 나머지를 제거합니다. **Fig.4는 깊이 $d=2$에서 세 노드를 유지하는 $W=3$ 사례**입니다. **[pp.19–20]** 2103.04931v4

**[해석]** 옵션은 **행동의 표현 방식**을 바꾸고, 가지치기는 **조사할 후보의 범위**를 줄입니다. 둘 다 계산을 절약하지만, 잘못된 옵션이나 영구적인 가지치기는 최적 경로를 탐색 대상에서 없앨 수 있습니다.

#### 휴리스틱의 영향 조절: Progressive win bias

원문 **식 (5), p.20**은 다음과 같습니다.

```math
P_i
=
W\frac{H_i}{T_i(1-\bar X_i)+1}.
```

$P_i$는 노드 $i$에 부여하는 편향 항, $H_i$는 휴리스틱 평가값, $T_i$는 방문 횟수, $\bar X_i$는 평균 보상, $W>0$는 휴리스틱의 영향력입니다. 이 항으로 탐색 기준에 사전 지식을 반영합니다. 2103.04931v4

> **용어 설명 — 휴리스틱:** 정확한 해답을 보장하지는 않지만 좋은 선택을 빠르게 찾도록 돕는 경험적 규칙입니다.  
> **용어 설명 — 편향:** 특정 종류의 선택이나 예측을 체계적으로 선호하는 성향입니다.

**[수식 해석]** 이 식은 방문 수 자체보다 패배에 해당하는 양에 반응합니다. 특히 $\bar X_i=1$이면 분모가 $1$이므로, 다른 조건이 일정할 때 **방문 수가 늘어난다는 이유만으로 편향 항이 감소하지는 않습니다**.

### 4.3 RAVE: 다른 상황의 행동 경험을 공유한다

**[원문 설명]** RAVE는 어떤 행동이 현재 노드에서 직접 선택된 경우뿐 아니라, 이후 롤아웃에서 등장한 경우의 결과도 활용합니다. 초기 표본이 적을 때 행동의 가치를 더 빨리 추정하려는 방법입니다. **[pp.14, 21]** 2103.04931v4 2103.04931v4

원문 **식 (6), p.21**은 다음과 같습니다.

```math
\bar Z(s,a)
=
(1-\beta(s,a))
\frac{W(s,a)}{N(s,a)}
+
\beta(s,a)
\frac{\bar W(s,a)}{\bar N(s,a)}.
```

$\bar Z(s,a)$는 결합된 행동 평가값입니다. $W,N$은 직접 선택으로 얻은 누적 보상과 횟수이고, $\bar W,\bar N$은 이후 시뮬레이션에서 해당 행동이 등장한 경우까지 활용하는 누적 보상과 횟수입니다. $\beta(s,a)$는 두 추정값의 혼합 비중이며, 직접 방문이 늘어나면 감소하도록 설계합니다. 2103.04931v4

> **용어 설명 — AMAF:** “이후에 등장한 행동을 처음에 선택했어도 비슷한 정보를 얻었을 것”이라고 간주하여 통계를 공유하는 방식입니다.

**[해석]** 이는 신경망 없이도 가능한 일종의 경험 공유입니다. 다만 행동의 좋고 나쁨이 위치·순서·주변 상황에 크게 의존하면, 다른 상황의 경험이 잘못된 정보를 줄 수 있습니다. 리뷰도 신뢰하기 어려운 롤아웃 정보가 RAVE의 성능을 악화시킬 수 있다고 설명합니다. **[p.22]** 2103.04931v4

### 4.4 불완전정보 처리: “상태를 모른다”는 사실을 구조에 반영한다

**[원문 설명]** 결정화는 상대의 패나 숨겨진 정보를 하나씩 표본으로 정하여, 각각을 완전정보 문제처럼 탐색하는 방법입니다. 구현은 직관적이지만, 전략 융합·비국소성·여러 트리 간 계산 예산 분산이라는 문제가 있습니다. **[pp.26–27, Fig.5]** 2103.04931v4

> **용어 설명 — 결정화:** 불확실한 요소에 구체적인 값을 넣어 가능한 세계 하나를 만드는 것입니다.  
> **용어 설명 — 전략 융합:** 실제 플레이어는 구별할 수 없는 두 상황에서, 탐색 알고리즘이 숨겨진 정답을 아는 것처럼 서로 다른 행동을 선택하는 오류입니다.  
> **용어 설명 — 비국소성:** 현재 하위 문제만 독립적으로 최적화해서는 전체 게임의 올바른 전략을 얻기 어려운 성질입니다.

정보집합 MCTS, 즉 ISMCTS는 플레이어가 구별할 수 없는 상태들을 하나의 정보집합으로 묶어 통계를 공유합니다. **트리 노드가 반드시 완전히 알려진 물리적 상태 하나를 뜻할 필요가 없다는 점**이 핵심입니다. **[pp.27–28, Fig.6]** 2103.04931v4

**한계.** 정보집합을 사용한다고 해서 모든 불완전정보 게임에서 균형 전략으로 수렴하는 것은 아닙니다. 리뷰는 특정 비교에서 OOS가 내시균형에 가깝게 수렴한 반면 ISMCTS는 그렇지 않았다는 결과를 별도로 소개합니다. **[p.28]** 2103.04931v4

> **용어 설명 — 내시균형:** 다른 플레이어의 전략이 고정되어 있을 때, 누구도 혼자 전략을 바꿔 기대 이익을 높일 수 없는 상태입니다.

### 4.5 신경망 결합: 정책과 가치를 학습한다

**[원문 설명]** 리뷰가 설명하는 AlphaGo 구조는 정책망과 가치망을 사용합니다. 정책망은 유망한 행동을 안내하고, 가치망은 현재 상태에서의 게임 결과를 예측합니다. 리뷰는 초기 정책을 전문가 기보로 학습한 뒤 자기 대국을 통한 강화학습으로 개선하고, 그 대국 결과로 가치망을 학습하는 과정을 설명합니다. 초기 지도학습 정책망은 13개 층으로 기술되어 있습니다. **[p.37, Fig.8 p.38]** 2103.04931v4

> **용어 설명 — 가치함수:** 어떤 상태나 행동에서 앞으로 기대할 수 있는 결과를 수치로 나타내는 함수입니다.  
> **용어 설명 — 자기 대국:** 현재 에이전트 또는 그 변형끼리 대결하면서 학습 데이터를 생성하는 방식입니다.  
> **용어 설명 — 합성곱 신경망:** 보드나 영상의 지역적 공간 패턴을 반복적으로 처리하는 신경망입니다.

원문 **식 (11), p.37**은 정책의 사전 정보를 이용한 선택을 다음과 같이 제시합니다.

```math
a^*
=
\text{arg\,max}_{a\in A(s)}
\left[
Q(s,a)+\frac{P(s,a)}{1+N(s,a)}
\right].
```

$P(s,a)$는 행동의 사전 확률이며, 나머지 기호는 기본 UCT와 같습니다. **이 식은 해당 리뷰에 인쇄된 표현입니다. 이를 후대 구현에서 사용하는 모든 PUCT 변형의 완전한 공통식으로 이해해서는 안 됩니다.** 2103.04931v4

> **용어 설명 — 사전 확률:** 본격적으로 탐색하기 전에 모델이 예상하는 행동의 유망성입니다.

리프 노드 평가는 원문 **식 (12), p.38**처럼 가치망 예측과 롤아웃 결과를 결합합니다.

```math
V(s_L)
=
(1-\lambda)\upsilon_\Theta(s_L)
+
\lambda z_L.
```

$s_L$은 리프 상태, $V(s_L)$은 결합된 평가값, $\upsilon_\Theta(s_L)$은 파라미터 $\Theta$를 가진 가치망의 예측, $z_L$은 롤아웃 결과, $\lambda$는 혼합 비중입니다. 2103.04931v4

**[해석]** 이 구조의 장점은 모든 후보를 끝까지 시뮬레이션하지 않고도 평가할 수 있다는 것입니다. 반대로 잘못 학습된 가치가 탐색 방향을 오도할 수 있으므로, 탐색과 신경망을 결합했다는 사실만으로 오류가 자동 상쇄되지는 않습니다. 저자들도 데이터의 양·질과 학습 상태의 다양성을 주요 과제로 제시합니다. **[pp.46–47]** 2103.04931v4 2103.04931v4

### 4.6 시간차 학습: 결과를 기다리지 않고 예측을 갱신한다

원문 **식 (15), p.44**는 다음과 같습니다.

```math
V(s_t)
\leftarrow
V(s_t)
+
\alpha
\left[
R_{t+1}
+
\gamma V(s_{t+1})
-
V(s_t)
\right].
```

$t$는 시간 단계, $s_t$는 현재 상태, $R_{t+1}$은 다음 단계에서 관측한 보상, $\alpha$는 학습률, $\gamma$는 미래 보상 할인율입니다. 대괄호 안은 새 정보와 기존 예측의 차이입니다. 2103.04931v4

> **용어 설명 — 시간차 학습, TD:** 다음 상태의 예측과 새 보상을 이용하여 현재 상태의 예측을 조금씩 수정하는 방법입니다.  
> **용어 설명 — 부트스트래핑:** 실제 최종 결과가 아니라 다른 예측값을 학습 목표의 일부로 사용하는 것입니다.

원문 **식 (16), p.44**는 TD 추정과 MCTS의 표본 평균을 결합합니다.

```math
Q_{\text{TD-UCT}}
=
\omega V
+
(1-\omega)Q
+
C\sqrt{\frac{\ln N(s)}{N(s,a)}}.
```

$V$는 TD 기반 추정값, $Q$는 기존 MCTS 평균값, $\omega$는 두 추정값의 혼합 비중입니다. $C,N(s),N(s,a)$는 앞서 정의한 탐색 관련 기호입니다. 이 결합은 주로 선택과 결과 갱신 단계에 영향을 줍니다. 2103.04931v4

**[리뷰가 인용한 결과]** 특정 TD-UCT와 AMAF 결합은 검토한 네 게임에서 다른 비교 변형보다 좋은 성능을 보였고, 다른 TD 기반 롤아웃 연구는 다섯 게임 중 네 게임에서 기본 MCTS를 능가했습니다. 이는 유용한 실험 결과지만, 모든 게임에 대한 보장은 아닙니다. **[p.45]** 2103.04931v4

### 4.7 그 밖의 구조적 확장

**진화적 MCTS.** 일부 방법은 휴리스틱이나 정책을 진화시키고, 다른 방법은 트리 자체의 의미를 바꿉니다. 예를 들어 Fig.12의 Evolutionary MCTS에서는 **노드가 행동 하나의 결과 상태가 아니라 전체 행동 시퀀스**, 간선이 그 시퀀스에 가하는 변이 연산입니다. 따라서 기본 MCTS와 노드 수만 직접 비교하는 것은 부적절할 수 있습니다. **[pp.48–53, Fig.12]** 2103.04931v4 2103.04931v4

> **용어 설명 — 진화적 최적화:** 후보 해를 여러 개 유지하고, 선택·변이·조합을 반복하여 더 좋은 해를 찾는 방법입니다.

**병렬 MCTS.** 리프 병렬화는 같은 새 노드에서 여러 롤아웃을 수행하고, 루트 병렬화는 독립된 트리를 만든 뒤 통계를 합치며, 트리 병렬화는 하나의 트리를 여러 작업자가 공유합니다. 공유 트리에서는 가상 손실을 사용하여 여러 작업자가 같은 경로에 몰리는 현상을 줄입니다. **[pp.66–67]** 2103.04931v4

> **용어 설명 — 가상 손실:** 현재 다른 작업자가 조사하는 경로에 일시적인 불이익을 주어 중복 탐색을 줄이는 장치입니다.

**게임 외 응용.** 리뷰는 계획, 로봇 제어, 보안 전략, 화학 합성, 스케줄링, 차량 경로 문제를 다룹니다. 여기서는 행동이 바둑의 착수가 아니라 반응 선택, 작업 배정, 경로 수정 등이 됩니다. 예를 들어 화학 합성의 3N-MCTS는 롤아웃 정책, 변환 가능성 필터, 확장 정책에 신경망을 사용합니다. **[pp.54–65, 특히 pp.62–63]** 2103.04931v4 2103.04931v4 2103.04931v4

### 5.2 통계적으로 어디까지 말할 수 있는가?

**[검증 제한] 리뷰에 통계 정보가 없다는 사실과, 원 실험에 통계 분석이 없다는 주장은 다릅니다.** 위 수치들은 리뷰만으로 반복 실험 수, 분산, 신뢰구간, 모든 비교 조건을 일관되게 복원하기 어렵습니다. 따라서 “유의하게 우수하다”는 판단은 원 실험의 통계 설계를 추가 확인해야 합니다.

**[잠재적 취약성] 파라미터 선택과 평가가 충분히 분리되었는지 확인해야 합니다.** 리뷰는 많은 연구가 탐색 상수·깊이·정책 관련 파라미터를 경험적으로 최적화한다고 설명합니다. 여러 조합 중 가장 좋은 설정만 보고하면, 평가 데이터에도 우연히 잘 맞는 설정이 선택되었을 가능성을 따져야 합니다. 다만 이 리뷰만으로 각 원 연구에 평가 데이터 누수가 있었다고 단정할 수는 없습니다. **[p.7]** 2103.04931v4

> **용어 설명 — 데이터 누수:** 평가에만 사용해야 할 정보가 학습이나 설정 선택에 들어가서 성능이 실제보다 좋아 보이는 문제입니다.

**[비교 불가] 서로 다른 계산 예산과 지표를 한 순위로 합칠 수 없습니다.** 같은 시뮬레이션 횟수라도 신경망 평가를 사용하는 방법과 단순 롤아웃의 실행 비용은 다릅니다. 승률, 게임 점수, 작업 완료시간, 처리 속도 또한 서로 다른 측정 대상입니다.

**[해석]** 연구자에게 필요한 결론은 “어떤 수정법이 몇 퍼센트 가장 좋다”가 아니라, **어떤 조건에서 어떤 비용을 지불하고 어떤 품질 지표가 개선되었는가**입니다.

### 7.2 후속 방법을 이해하는 핵심 수식

#### A. MuZero: 탐색에 필요한 환경 모델을 학습한다

MuZero의 핵심 구조는 다음과 같습니다.

$$
s^0=h_\theta(o_{1:t}),
$$

$$
(r^k,s^k)=g_\theta(s^{k-1},a^k),
$$

$$
(p^k,v^k)=f_\theta(s^k).
$$

$o_{1:t}$는 현재까지의 관측, $h_\theta$는 관측을 내부 상태로 바꾸는 표현 함수, $g_\theta$는 행동 이후의 보상과 다음 내부 상태를 예측하는 함수, $f_\theta$는 정책과 가치를 출력하는 함수입니다. $k$는 실제 시간이 아니라 탐색 속에서 앞으로 진행한 깊이이며, $\theta$는 학습 파라미터입니다. **[MuZero pp.3–4, Fig.1]** [arXiv](https://arxiv.org/pdf/1911.08265)

> **용어 설명 — 잠재상태:** 실제 관측의 모든 세부사항을 그대로 보존하지 않고, 의사결정에 필요한 정보를 압축한 내부 표현입니다.

**[해석]** 리뷰의 정책·가치 학습에 더해 **무엇이 다음에 일어나는가**까지 학습하는 방향입니다. 일반화가 좋아지려면 정책뿐 아니라 이 내부 전이 모델도 새로운 상황에서 유효해야 합니다.

#### B. ME-MCTS: 여러 추정기를 신뢰도에 따라 결합한다

논문의 결합 구조를 표기를 단순화하여 나타내면 다음과 같습니다.

```math
\hat Q
=
\sum_{j=1}^{m}\lambda_j\hat Q_j,
\qquad
\lambda_j\ge 0,
\qquad
\sum_{j=1}^{m}\lambda_j=1.
```

$\hat Q_j$는 서로 다른 문맥을 사용하는 $j$번째 가치 추정값, $\lambda_j$는 혼합 가중치, $m$은 추정기의 개수입니다. 저자들은 추정 오차를 줄이는 방향으로 가중치를 정하지만, 실제 구현에서는 추정기 사이의 상호의존성을 무시하는 근사를 사용합니다. **[ME-MCTS p.4034, §3]** [IJCAI](https://www.ijcai.org/proceedings/2021/0555.pdf)

**[해석]** 일반화는 하나의 강력한 추정기에 모든 판단을 맡기는 것뿐 아니라, **서로 다른 범위의 경험을 공유하는 추정기를 상황에 맞게 결합하는 문제**로도 볼 수 있습니다.

#### C. Gumbel 기반 선택: 유한한 예산에서 후보를 더 체계적으로 비교한다

핵심 행동 선택은 다음 형태입니다.

```math
a^*
=
\text{arg\,max}_{a\in A_{\text{cand}}}
\left[
g(a)+\ell(a)+\sigma(\hat q(a))
\right].
```

$A_{\text{cand}}$는 표본으로 선택한 후보 행동 집합, $g(a)$는 Gumbel 잡음, $\ell(a)$는 정책의 로짓, $\hat q(a)$는 행동 가치 추정, $\sigma$는 가치를 점수에 반영하는 증가 함수입니다. **[Gumbel 논문 pp.3–4, Algorithm 1]** [David Silver](https://davidstarsilver.wordpress.com/wp-content/uploads/2025/04/gumbel-alphazero.pdf)

> **용어 설명 — 로짓:** 확률분포로 변환하기 전의 모델 출력 점수입니다.  
> **용어 설명 — Gumbel 잡음:** 확률적 후보 선택에 사용하는 특정 분포의 무작위 값입니다.  
> **용어 설명 — 순차적 절반 제거:** 후보들에게 계산을 배분한 뒤 낮은 점수의 절반을 제거하고, 남은 후보를 다시 비교하는 절차입니다.

**[해석]** 이 방향은 기존 리뷰의 “탐색과 활용을 어떻게 조절할 것인가”를 발전시킵니다. 그러나 제한된 조건의 정책 개선 증명과, 실제 부정확한 가치 모델을 사용했을 때의 안정적인 개선은 별도로 검증해야 합니다.

### 7.3 최신 연구에서도 주의해야 할 통계와 비교 조건

**① LATS의 92.7%는 ‘한 번 생각한 모델’의 성능이 아닙니다.** HumanEval에서는 확장 시 5개 후보를 만들고 8회 반복하며, 생성한 테스트와 컴파일러 피드백을 사용한 뒤 최종 후보 하나를 평가합니다. 일부 비교 기준은 161문제를, LATS는 164문제를 사용한다는 주석도 있습니다. 따라서 **[직접 비교 주의]** 표시가 필요합니다. **[LATS p.7, §5.2, Table 4 및 각주]** [arXiv](https://arxiv.org/pdf/2310.04406)

**② ReST-MCTS*의 자기개선은 모든 평가에서 단조롭지 않습니다.** Table 2에서 LLaMA-3-8B-Instruct의 MATH는 향상되지만, C-Eval Hard는 초기 26.32에서 두 번째 반복 후 25.00입니다. 따라서 평균 개선을 “모든 분포 밖 능력의 지속적 향상”으로 해석하면 안 됩니다. 이 방법은 최종 정답 정보도 활용하므로, 중간 단계의 사람 주석이 없다는 사실을 모든 정답 정보가 불필요하다는 뜻으로 읽어서도 안 됩니다. **[ReST-MCTS* p.7, Table 2; §4.2]** [arXiv](https://arxiv.org/pdf/2406.03816)

**③ ReSCALE의 오차 막대는 비교 대상과 의미가 다릅니다.** Table 1의 탐색 방법은 **하이퍼파라미터 설정들 사이의 평균±표준편차**, Best-of-N은 **세 무작위 시드 사이의 평균±표준편차**입니다. 또한 GSM8K에서 큰 탐색 예산은 16,000–18,000토큰인데 Best-of-N은 약 3,500토큰입니다. 따라서 **[통계적 해석 제한]**, **[동일 계산량 비교 아님]**으로 표시해야 합니다. **[ReSCALE p.4, Table 1]** [arXiv](https://arxiv.org/pdf/2603.21162)

> **용어 설명 — 무작위 시드:** 실험의 무작위 선택을 재현하기 위한 초기값입니다.  
> **용어 설명 — 표준편차와 신뢰구간:** 표준편차는 관측값의 퍼짐을 나타내고, 신뢰구간은 추정하려는 평균 등의 불확실성을 나타냅니다. 두 개념은 같지 않습니다.  
> **용어 설명 — Best-of-N:** 답을 여러 개 생성한 뒤 평가 기준에 따라 가장 좋은 하나를 선택하는 방법입니다.

## 8. 모델의 일반화 성능: 무엇이 확인되었고 무엇이 아직 가설인가?

### 8.1 원문에서 일반화에 관한 근거의 강도

| 일반화에 관한 내용 | 원문이 제공하는 근거 | 판단 |
|---|---|---|
| 직접 방문하지 않은 상태를 학습 모델로 평가 | 신경망 등의 근사 능력에 관한 논의 | 가능성에 관한 설명이며, 일반적인 성능 보장은 아님 |
| 작은 지도에서 학습한 평가함수를 큰 지도에 사용 | 지도 크기에 독립적인 표현을 사용하는 RTS 연구 소개 | 구조적 전이에 관한 구체적인 인용 사례 |
| 지역 패턴으로 학습한 정책을 다른 보드 크기에 사용 | Hex 정책의 진화적 학습 연구 소개 | 특정 표현·문제에서의 전이 사례 |
| 체스판을 8×8에서 9×9로 확장 | 저자들의 설명용 사고실험 | **실측 결과가 아님** |
| 탐색 데이터를 학습 모델로 이전 | MCTS 교사 구조와 결론의 제안 | 일반화를 위한 방법적 방향이지 성공 보장 자체는 아님 |

각 근거의 위치는 **p.41, p.46–47, p.50, p.76**입니다. 2103.04931v4 2103.04931v4 2103.04931v4 2103.04931v4

**[해석]** “보지 못한 상태를 입력받아 값을 출력할 수 있다”와 “그 값이 정확하다”는 다릅니다. 또한 “어떤 알고리즘을 여러 게임에 다시 학습시킬 수 있다”와 “한 번 학습한 모델이 새로운 게임에서도 잘한다”도 다릅니다.

### 8.2 일반화 향상 가능성이 높은 연구 방향

#### 방향 A. 상태의 세부 모양보다 재사용 가능한 구조를 학습한다

**[제안]** 보드의 절대 좌표나 특정 지도 이름보다, 물체 사이의 관계·지역 패턴·하위 목표처럼 크기나 표면 표현이 바뀌어도 유지되는 정보를 학습하는 것이 유망합니다.

이 제안은 원문의 지도 독립적 평가함수 및 지역 패턴 전이 사례와 연결됩니다. 다만 **표현이 크기에 독립적이라는 사실만으로 큰 문제에서도 정확한 판단이 보장되지는 않으므로**, 크기 증가에 따른 성능 곡선을 별도로 측정해야 합니다. **[원문 pp.41, 50]** 2103.04931v4 2103.04931v4

#### 방향 B. 탐색 결과를 정책뿐 아니라 기억과 추상화로도 이전한다

**[제안]** 탐색 경험의 재사용 경로를 세 가지로 비교할 필요가 있습니다. 하나는 신경망 정책에 학습시키는 방식, 다른 하나는 재사용 가능한 상태–행동 통계로 유지하는 방식, 마지막은 검색 가능한 추상 경험으로 저장하는 방식입니다.

이는 원문의 MCTS 교사 구조, ME-MCTS의 여러 추정기 결합, SGA-MCTS의 경험 검색을 함께 놓고 비교할 수 있는 실험 설계입니다. 세 방식은 **같은 일반화 메커니즘이 아니라 서로 다른 저장·재사용 방식**입니다. 2103.04931v4 [IJCAI](https://www.ijcai.org/proceedings/2021/0555.pdf) [ACL Anthology](https://aclanthology.org/2026.findings-acl.60.pdf)

#### 방향 C. 새로운 상황에서 학습된 지식의 영향력을 조절한다

**[제안]** 신경망이나 휴리스틱이 자신 있어 보인다는 이유만으로 후보를 영구 제거하기보다, 예측이 불안정한 상황에서는 더 다양한 후보에 탐색 예산을 배분하는 구조를 검토해야 합니다.

중요한 비교는 **항상 같은 강도로 지식을 사용하는 방법**과 **상황별로 지식의 비중을 조절하는 방법**입니다. 원문의 편향 조절과 RAVE 혼합은 이러한 설계의 출발점이지만, 새로운 분포에서의 신뢰도 판단까지 해결한 것은 아닙니다. **[pp.20–22]** 2103.04931v4 2103.04931v4

#### 방향 D. 다양한 상대와 실패 사례를 학습 데이터에 포함한다

**[제안]** 자기 대국에서 자주 나타나는 전략만 학습하는 대신, 드문 반격·새로운 상대 정책·의도적으로 취약점을 노리는 상대를 포함한 평가가 필요합니다.

원문은 고정된 휴리스틱 플레이어가 만든 데이터가 비슷한 상태에 편중될 수 있다고 경고합니다. 이후의 적대적 바둑 정책 연구는, 높은 평균 실력에도 특정 상대 전략에 대한 취약성이 남을 수 있음을 보여줍니다. **[원문 p.47; Wang et al. p.6]** 2103.04931v4 [arXiv](https://arxiv.org/pdf/2211.00241)

### 8.3 실제 후속 연구에 권하는 평가 설계

다음은 **원문에 없는 추가 연구 설계 제안**입니다.

| 평가 축 | 제안하는 실험 |
|---|---|
| 새로운 상태 | 같은 게임의 새로운 초기 상태와 다른 진행 경로를 평가한다 |
| 구조 변화 | 지도·보드 크기, 객체 수, 계획 길이를 변화시킨다 |
| 규칙·상대 변화 | 새로운 규칙 변형과 학습에 없던 상대 정책을 분리해 평가한다 |
| 구성요소 기여 | 기본 MCTS, 모델만 사용, MCTS+모델, 탐색 교사로 학습한 모델을 비교한다 |
| 계산량 | 시뮬레이션 수뿐 아니라 실제 시간, 모델 호출 수, 토큰 수, 메모리도 기록한다 |
| 통계 | 동일 문제에서 방법을 짝지어 비교하고, 여러 독립 실행과 문제 단위의 불확실성을 보고한다 |
| 실패 분석 | 평균 점수 외에 큰 실패의 빈도, 제약 위반, 성능이 감소한 과제를 공개한다 |

일반화 격차를 기록하는 보조 지표는 다음처럼 정의할 수 있습니다.

```math
J(\mathcal D,B)
=
\mathbb E_{x\sim\mathcal D}
\left[
\text{Score}(x;B)
\right],
```

```math
\Delta_{\text{shift}}(B)
=
J(\mathcal D_{\text{in}},B)
-
J(\mathcal D_{\text{out}},B).
```

$\mathcal D$는 문제 분포, $x$는 평가 문제, $B$는 계산 예산, $\text{Score}$는 높을수록 좋은 통일된 성능 지표입니다. $\mathcal D_{\text{in}}$은 학습과 유사한 분포, $\mathcal D_{\text{out}}$은 다른 분포입니다. 이 수식은 **본 답변의 평가 제안이지 원문 수식이 아닙니다**.

단, 분포 밖 문제 자체가 더 어렵다면 이 차이는 순수한 일반화 실패만 측정하지 않습니다. 따라서 난도가 비슷한 조건의 비교와, 모든 방법이 동일한 변화에 얼마나 민감한지에 대한 비교를 함께 해야 합니다.

오프라인 탐색을 사용하는 방법의 비용도 다음처럼 구분하는 것이 유용합니다.

```math
C_{\text{avg}}(n)
=
\frac{C_{\text{offline}}}{n}
+
C_{\text{online}}.
```

$C_{\text{offline}}$은 사전 탐색·학습·기억 구축 비용, $C_{\text{online}}$은 문제 하나를 실제 처리하는 비용, $n$은 준비 결과를 재사용한 문제 수입니다. 이 역시 **비용 평가를 위한 제안**입니다. 준비 비용이 큰 방법은 재사용 횟수가 충분할 때만 비용상 유리할 수 있습니다.

## 10. 결론: 저자들의 시사점과 추가 연구 방향

### 10.1 저자들이 제시한 시사점

**[저자 종합]** 결론에서 제시하는 주요 방향은 **MCTS와 기계학습의 결합**, **AutoMCTS를 통한 자기적응**, **편향을 과도하게 늘리지 않는 도메인 지식 활용**, **인간 전문가의 직접적인 탐색 지원**, **게임 외 새로운 분야로의 확장**, **실시간 게임에서의 효율성과 행동 통제 개선**입니다. 이는 구체적인 하나의 후속 모델이나 실험 일정을 약속한 계획이 아니라, 연구 공동체를 향한 전망입니다. **[pp.70, 74–76]** 2103.04931v4 2103.04931v4

일반화와 가장 밀접한 제안은 **MCTS를 오래 실행하여 좋은 학습 데이터를 만든 뒤, 빠르고 재사용 가능한 학습 모델로 옮기는 것**입니다. **[p.76]** 2103.04931v4

### 10.2 2020년 이후 연구를 반영한 평가

**[해석]** 이후의 관련 연구는 이 리뷰의 문제 분류가 여전히 유용함을 보여줍니다. MuZero 계열은 학습된 표현과 모델을, ME-MCTS는 경험 공유를, Gumbel 계열은 유한 예산 배분을, ReST-MCTS*와 SGA-MCTS는 탐색 경험의 재사용을 발전시키는 방향으로 이해할 수 있습니다.

다만 이것을 **이 리뷰가 해당 연구를 직접 유발했다는 인과적 영향**으로 주장할 근거는 여기서 확인하지 않았습니다. 이 논문의 영향은 우선 **서로 다른 응용을 같은 설계 문제로 비교할 수 있게 하는 개념적 틀**에서 평가하는 것이 적절합니다.

### 10.3 우선순위가 높은 추가 후속 연구

**[제안] 가장 중요한 후속 연구는 ‘일반화를 측정하도록 설계된 적응형 MCTS’입니다.** 특정 벤치마크의 평균 점수를 최대화하는 데서 멈추지 않고, 새로운 상태·크기·규칙·상대에 대해 어떤 지식이 전이되고 어떤 지식이 실패하는지를 측정해야 합니다.

이를 위해서는 재사용 가능한 표현이나 기억, 신뢰도에 따른 탐색 배분, 다양한 상대와 실패 사례, 독립적인 결과 검증, 전체 계산 비용을 함께 다루는 연구가 필요합니다. 특히 언어모델 응용에서는 **추론 시 더 많이 탐색하여 정답률을 높인 것**과 **탐색으로 만든 데이터가 모델 자체의 미지 문제 해결 능력을 높인 것**을 분리해 입증해야 합니다.

**최종 판단:** 이 리뷰는 MCTS가 왜 다양한 문제로 확장될 수 있는지를 잘 설명하지만, “수정된 MCTS는 일반화가 잘된다”는 보편적 결론을 입증하지는 않습니다. 가장 설득력 있는 발전 방향은 **탐색으로 얻은 경험을 재사용 가능한 지식으로 바꾸고, 그 지식의 오류와 적용 범위를 명시적으로 검증하는 것**입니다.
